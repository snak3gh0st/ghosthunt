# Ghosthunt product

## Register

product

## Users

An independent bug bounty researcher working on a Mac, selecting authorized programs,
reviewing public information and code, validating hypotheses and preparing HackerOne reports.

## Product Purpose

Run the Ghosthunt workflow from one command center: program and scope, tools, live process
output, evidence, validated reports and actual reward tracking. Local AI reduces API use.

## Brand Personality

Technical, direct, investigative. The user explicitly requested a hacker command center
with glitch details and a real embedded terminal.

## Anti-references

Google Maps lead scraping, sales outreach and a flat wall of equally prominent tools do
not fit this project. Unavailable integrations must not appear operational.

## Design Principles

- Keep the selected program and target visible before any execution.
- Prioritize actions that can run now; make blocked tools discoverable with a reason.
- Show real process state, output and evidence rather than decorative activity.
- Separate collection, investigation and validated findings.
- Keep local AI the default and make cloud use explicit.

## Accessibility & Inclusion

Use keyboard-operable controls, visible focus, labelled inputs, readable contrast,
responsive layouts and reduced-motion support as implementation defaults.
